# テスト計画

各テスト結果には実施日、環境、データ版、実施者、期待値、実測値、証跡、合否、課題を記録する。未実施と未合格を完成扱いしない。

## 単体テスト

- 円金額、数量、日付、NULL、ゼロの型と制約。
- D/P/Tおよび3差額の計算。計算しても元値を変えないこと。
- 月曜予定休業と例外営業実績の優先規則。
- 状態遷移（暫定、要確認、確認済み、確定、差戻し）。
- 確定後の新版作成と修正履歴。
- ファイルハッシュと重複候補検出。
- 商品価格の適用期間。
- 権限判定とマスキング。

## 結合テスト

- 原本登録→手入力／既存データ取込→人の確認→承認→確定→分析→出力。OCRはVersion 1のテスト対象外。
- 日別、商品別、時間帯別の照合と要確認作成。
- 通帳明細と売上の対応付け、解除、再対応。
- 確定訂正後も旧版・原本・監査ログを参照できること。
- 同一ファイルの再取込で確定データが二重化しないこと。
- Codex版以外のDBやStorageへ接続できないこと。

## 端末テスト

- macOS: Safari、Chrome。
- Windows: Edge、Chrome。
- iPhone: Safari。
- Android: Chrome。
- 主要幅で、一覧、画像拡大、数値入力、確認、出力操作を検証する。
- 低速通信、切断、二重タップ、戻る、セッション切れを検証する。

対象OS・ブラウザの具体的な最低バージョンは本番公開前に確定する。

## データ移行テスト

- 2026年6月・7月のファイル数、行数、日付網羅性。
- 商品マスター、別名、価格、有効期間。
- 商品別・時間帯別の明細と合計。
- 通帳明細の入出金、残高、順序。
- 修正履歴と未解決の要確認事項。
- 原本ハッシュとDBレコードの追跡。
- 再実行可能性と重複防止。
- 7月8日・9日の二者重点検証。

## バックアップ復元テスト

- DB、原本、設定、暗号鍵管理情報の対象範囲を確認する。
- 本番から隔離された環境へ復元する。
- 復元後の件数、ハッシュ、主要合計、権限、監査履歴を照合する。
- 目標復旧時間（RTO）と許容損失時間（RPO）は決定後に合否判定へ加える。
- 復元不能ならバックアップ成功扱いにしない。

## Excel出力テスト

- 承認済み既存シート構成、名称、順序、列、書式、計算式の再現。
- DBの確定値とセル値の一致。
- 暫定・要確認値を含む場合の明示。
- D/P/T不一致と差額の表示。
- 日付、円表示、文字コード、長い商品名、空欄とゼロ。
- Mac版・Windows版Excelでの表示と再計算。
- 同一データ版・条件からの再生成結果。
- Mac版Excelで開いた際に修復警告が表示されないこと。
- Windows版Excelで開いた際に修復警告が表示されないこと。
- 保存して閉じ、再読込した後も日付、数量、金額および集計値が出力直後と一致すること。
- 承認された既存帳票のシート構成、シート名、順序が維持されること。
- 日付は日付型、数量は数値型、金額は数値型として格納され、表示書式だけで型を偽装していないこと。

上記5項目のいずれかが不合格の場合、Excel互換の完成条件は未達とする。

## ChatGPT版との比較テスト

- 同一ハッシュの入力資料セットを、独立した環境へ投入する。
- 比較用の共通定義に従い、原本数、取込件数、D/P/T、差額、要確認、商品対応、Excel出力を比較する。
- 値が一致しても、推測や自動調整で作られた値は不合格とする。
- 差異は優劣を推測せず、入力・仕様・処理・確認判断のどこで生じたか記録する。

## 合否と不具合

重大度、再現手順、影響データ、回避策、修正版、再テスト結果を記録する。重大なデータ改変、権限漏れ、原本追跡不能、バックアップ復元不能は本番公開阻止条件とする。

## Phase 1B 商品マスター

自動テストでは合成データ専用リポジトリを使用し、次を検証する。

- 商品新規登録。
- 商品コード一意制約相当。
- 商品名編集。
- 価格変更時の旧価格終了と新価格履歴追加。
- 無効化と再有効化。
- 商品コード／商品名検索、カテゴリ、有効状態の絞り込み。
- 販売終了日が開始日より前の場合の拒否。
- 負の標準価格の拒否。

画面確認では、商品一覧、登録、編集、価格履歴、日本語入力エラー、Supabase未設定案内、検索・絞り込み、画面遷移、ブラウザコンソールを確認する。

本番ビルドではTypeScript、ESLint、Next.jsルート生成がエラーなく完了することを確認する。実Supabaseへのマイグレーション適用、RLS、実トランザクション、ネットワーク障害時の挙動は接続先未作成のため未確認とする。
