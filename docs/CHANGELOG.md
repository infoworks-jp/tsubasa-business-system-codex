## Version 0.3

| 項目 | 内容 |
|---|---|
| 変更日 | 2026-07-17 |
| 追加・変更内容 | 商品マスターの項目・カテゴリ・価格履歴を詳細化。券売機写真一覧と処理フローを追加し、元写真の永久保存・上書き禁止を明記。通帳照合の一致／要確認／未照合を色と文字で表示。経営者ホームをログイン後初期画面として指定項目に統一。Excel互換の5つの完成条件を追加 |
| 変更理由 | Phase 0最終レビューとして、商品識別、原本保全、照合状態、経営判断画面、帳票互換性の受入基準を明確にするため |
| 影響する文書 | `docs/SPECIFICATION.md`、`docs/SCREEN_LIST.md`、`docs/DATA_MODEL.md`、`docs/QUALITY_DASHBOARD.md`、`docs/TEST_PLAN.md`、`docs/DECISIONS.md`、本書 |
| 承認状態 | 最終レビュー反映済み・Phase 0承認待ち |

### 詳細

- 商品コード、商品名、6カテゴリ、券売機ボタン・位置、販売期間、標準価格、将来原価、有効状態を定義した。
- 価格変更を過去値の上書きではなく適用期間付き履歴として定義した。
- 「営業日→券売機写真一覧→OCR（将来）→商品別→時間帯別→品質確認」の画面フローを追加した。
- 券売機元写真を永久保存し、削除・上書きしない規則を追加した。
- 通帳照合を緑＝一致、黄＝要確認、赤＝未照合とし、文字表示を必須にした。
- 経営者ホームをログイン後最初の画面とし、指定された10項目へ整理した。
- Mac／Windowsの修復警告、再読込後の値、シート構成、セル型をExcel完成条件へ追加した。
