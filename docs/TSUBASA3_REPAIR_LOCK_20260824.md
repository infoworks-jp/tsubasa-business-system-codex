# つばさ3 完全修復ロック

このブランチは 2026-08-24 の全期間監査・修復専用。

## 完了条件

「完成」「完全」「確定」と報告・表示してよいのは、2026-06-01 から最新営業日までについて以下をすべて満たした場合だけ。

1. 日計: 営業日の売上・客数・発行・精算が正本と一致。
2. 商品別: 月計は日計売上と一致。日別原本が存在する日は daily_journal_id まで紐付く。
3. 時間帯: 原本が存在する営業日は24時間行を持ち、発行数合計=日計発行数、時間帯売上+精算額=日計売上。
4. 原本: 見つかった券売機画像・旧正本を documents/source_files と対応づける。
5. 通帳: 売上入金を売上日単位で照合し、差額は理由を残す。
6. F/L/R: 仕入・人件費・家賃等は正本DBから算出し、手入力表示を正本扱いしない。
7. QA: 欠損を0扱いして合格にしない。未復元・未照合は必ず未確定表示。

- QA未合格の状態で公開画面に「確定データ」と表示しない。
